WHO LIVES WHERE? — интерактивная игра для 5 класса

Состав: index.html, style.css, script.js, images/neighbourhood.png.
Запуск: откройте index.html в браузере. Интернет не нужен.

GitHub: распакуйте ZIP и загрузите index.html, style.css, script.js и папку images в корень НОВОГО репозитория (например, neighbours). Сам ZIP загружать не нужно. Settings → Pages → Deploy from a branch → main → / (root) → Save.

8 предложений, 20 жилых этажей; ground floor — отдельный вход, как в британском английском. Новая игра меняет имена и этажи. Перетаскивайте имена или нажимайте на имя, затем на этаж. Занятый этаж возвращает прежнего жильца в список. Имя можно перенести на другой этаж; перетаскивание обратно в блок Ready to move in отменяет размещение. Return all names очищает дом. Проверка не ограничена.

Поле целиком вписывается в экран без прокрутки. Для удобного чтения используйте компьютер, проектор или планшет в горизонтальной ориентации; на узком телефоне поле уменьшается.

Никаких внешних библиотек, аккаунтов, аналитики или платных сервисов. Изменить имена можно в массиве residents файла script.js. Названия файлов и папки images сохраняйте строчными буквами.
